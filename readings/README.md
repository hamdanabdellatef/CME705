# Readings and references

This release links to sources instead of redistributing books, papers, or external slide decks.

## Core implementation references

- [NumPy user guide](https://numpy.org/doc/stable/user/)
- [PyTorch Learn the Basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)
- [PyTorch reproducibility notes](https://docs.pytorch.org/docs/stable/notes/randomness.html)
- [Week 10 transfer-learning reading](week10-transfer-learning.md), with a ConvNeXt-Tiny fixed-feature and staged fine-tuning example
- [PyTorch transfer learning for computer vision](https://docs.pytorch.org/tutorials/beginner/transfer_learning_tutorial.html)

## Evaluation and reporting

- [scikit-learn common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html), used as a language-independent guide to inconsistent preprocessing, leakage, and randomness
- [Model Cards for Model Reporting](https://doi.org/10.1145/3287560.3287596)
- [Datasheets for Datasets](https://doi.org/10.1145/3458723)

## Foundational deep-learning papers

- [Learning representations by back-propagating errors](https://www.nature.com/articles/323533a0)
- [ImageNet classification with deep convolutional neural networks](https://dl.acm.org/doi/10.1145/3065386)
- [Very Deep Convolutional Networks for Large-Scale Image Recognition](https://arxiv.org/abs/1409.1556)
- [Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385)
- [EfficientNet: Rethinking Model Scaling for Convolutional Neural Networks](https://arxiv.org/abs/1905.11946)
- [A ConvNet for the 2020s](https://arxiv.org/abs/2201.03545)
- [ConvNeXt V2](https://arxiv.org/abs/2301.00808)
- [Long Short-Term Memory](https://doi.org/10.1162/neco.1997.9.8.1735)
- [Attention Is All You Need](https://arxiv.org/abs/1706.03762)
- [Auto-Encoding Variational Bayes](https://arxiv.org/abs/1312.6114)

Each module identifies why a reading is useful. Students should record the exact version used and distinguish primary papers from tutorials.
