# Convolutional networks

**Guiding question:** How do local connectivity and shared filters learn spatial representations?

## Learning outcomes

- calculate convolution and pooling output sizes;
- explain channels, filters, stride, and padding;
- trace tensor shapes through a CNN;
- train a compact PyTorch CNN;
- inspect errors or intermediate representations without overstating them.

## Topics

- 2D convolution
- pooling
- receptive fields
- CNN architecture history
- backpropagation through convolution
- feature inspection

## Evidence of learning

A shape-checked CNN, a justified evaluation, and an analysis of representative errors.

## Place in the course

Weeks 9–10 and the project's method/results reviews. Consult the [course schedule](../../schedule.md) for the associated lab and project milestone.
