# Optimization

**Guiding question:** How do loss gradients and update schedules change model parameters?

## Learning outcomes

- derive a gradient update for a simple differentiable model;
- compare batch, stochastic, and mini-batch updates;
- explain learning-rate effects;
- implement batches without omissions or duplicates;
- interpret a training curve without using it as test evidence.

## Topics

- loss surfaces
- gradient descent
- SGD and mini-batches
- learning rates
- momentum and convergence diagnostics

## Evidence of learning

A tested numpy optimizer and a plot or table that explains its behavior.

## Place in the course

Week 5 and the baseline experiment plan. Consult the [course schedule](../../schedule.md) for the associated lab and project milestone.
