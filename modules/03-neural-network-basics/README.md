# Neural-network basics

**Guiding question:** How do weighted transformations and nonlinear activations represent a function?

## Learning outcomes

- calculate a neuron's output;
- explain the role of bias and nonlinear activation;
- select an output activation for a task;
- express a feed-forward network in matrix form;
- relate architecture size to capacity and evidence needs.

## Topics

- neurons and layers
- matrix computation
- sigmoid, tanh, ReLU, and linear activations
- binary and multiclass outputs
- depth and representation

## Evidence of learning

A correct forward calculation and an explanation of every tensor dimension.

Week 4 and the literature comparison. Consult the [course schedule](../../schedule.md) for the associated lab and project milestone.
