# Backpropagation and losses

**Guiding question:** How does the chain rule assign responsibility for error through a network?

## Learning outcomes

- derive output- and hidden-layer gradients;
- implement backpropagation with explicit cached values;
- connect loss and output activation;
- check a gradient numerically;
- train a small nonlinear classifier.

## Topics

- computational graphs
- chain rule
- binary cross-entropy
- hidden-layer deltas
- gradient checking
- XOR

## Evidence of learning

A NumPy network that learns XOR and passes a finite or behavioral check.

Week 6 and the reproducible baseline. Consult the [course schedule](../../schedule.md) for the associated lab and project milestone.
