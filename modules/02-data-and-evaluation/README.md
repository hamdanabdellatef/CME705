# Data and evaluation

**Guiding question:** What evidence shows that a model will work on relevant unseen data?

## Learning outcomes

- separate training, validation, and final testing roles;
- choose random, stratified, grouped, or chronological splits;
- identify data leakage and fit preprocessing safely;
- select metrics for imbalance and asymmetric errors;
- analyze missingness, noise, bias, and feature quality.

## Topics

- generalization
- cross-validation
- data leakage
- metrics and uncertainty
- missing data and imbalance
- feature selection and baselines

## Evidence of learning

A written evaluation protocol that can be reviewed before model tuning.

## Place in the course

Weeks 2–3, the problem proposal, and every later experiment. Consult the [course schedule](../../schedule.md) for the associated lab and project milestone.
