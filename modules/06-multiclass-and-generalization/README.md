# Multiclass learning and generalization

**Guiding question:** How do model outputs, losses, regularization, and evaluation change for multiple classes and deep networks?

## Learning outcomes

- implement stable softmax and cross-entropy;
- explain one-hot targets and class indices;
- diagnose overfitting from separated curves;
- apply weight decay, early stopping, or dropout;
- propagate gradients correctly through inverted dropout.

## Topics

- multiclass outputs
- numerical stability
- overfitting
- regularization
- dropout
- robustness and error analysis

## Evidence of learning

A controlled comparison that changes one generalization intervention and reports class-specific effects.

## Place in the course

Weeks 7–8 and the controlled-experiment assignment. Consult the [course schedule](../../schedule.md) for the associated lab and project milestone.
