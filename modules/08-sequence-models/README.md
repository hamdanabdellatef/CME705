# Sequence models

**Guiding question:** How can a model represent order and dependencies across variable-length inputs?

## Learning outcomes

- identify common sequence-learning tasks;
- explain recurrent state and backpropagation through time;
- describe vanishing/exploding gradients;
- use an LSTM for sequence classification;
- explain why attention improves access to distant information and parallel computation.

## Topics

- sequence representations
- RNN state
- BPTT
- LSTM gates
- attention and transformer overview

## Evidence of learning

A shape-correct sequence model and a reasoned choice of what sequence information its output uses.

Week 11 and the specialization reading. Consult the [course schedule](../../schedule.md) for the associated lab and project milestone.
