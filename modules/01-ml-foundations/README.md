# Machine-learning foundations

**Guiding question:** How does a learning problem differ from a conventional programmed solution?

## Learning outcomes

- distinguish AI, machine learning, and deep learning;
- map application questions to classification, regression, clustering, or representation learning;
- describe training, inference, features, targets, parameters, and hyperparameters;
- state a testable learning objective and a simple baseline.

## Topics

- problem formulation
- supervised and unsupervised learning
- classification and regression
- the ML workflow
- generalization and baselines

## Evidence of learning

A task statement with an input, output or structure to learn, unit of observation, intended use, and baseline.

## Place in the course

Weeks 1–2 and the research-interest memo. Consult the [course schedule](../../schedule.md) for the associated lab and project milestone.
